📚 IV. 물질의 상태 변화 핵심 요점 정리

시험 완벽 대비

1️⃣ 물질의 세 가지 상태 & 입자의 운동

  • 입자의 운동: 모든 물질을 이루는 입자는 스스로 끊임없이 운동함.
  • 확산: 입자가 스스로 운동하여 주변으로 퍼져 나가는 현상 (예: 향수 냄새, 홍차 우러남).
  • 증발: 액체 표면에서 입자가 기체로 변해 날아가는 현상 (예: 빨래 마름, 손 소독제 마름).
  • 상태별 특징:
    • • 고체: 모양과 부피 일정, 입자 배열 매우 규칙적, 진동만 함.
    • • 액체: 모양은 변하나 부피 일정, 흐르는 성질, 불규칙 배열.
    • • 기체: 모양과 부피 모두 쉽게 변함, 입자 거리 매우 멀고 활발함.

2️⃣ 상태 변화와 입자 배열 (질량과 부피)

  • 상태 변화 종류:
    • • 융해: 고체 → 액체 (버터 녹음) / 응고: 액체 → 고체 (촛농 굳음)
    • • 기화: 액체 → 기체 (물 끓음) / 액화: 기체 → 액체 (컵 표면 물방울)
    • • 승화: 고체 ↔ 기체 직접 변화 (드라이아이스 크기 줄어듦, 서리)
  • 질량과 성질: 상태가 변해도 입자의 종류와 개수는 변하지 않으므로 질량과 성질은 그대로 유지됨.
  • 부피 변화: 일반적으로 [기체 > 액체 > 고체] 순으로 부피가 큼. (단, 물은 얼 때 육각형 구조를 형성하여 부피가 증가함!)

3️⃣ 열에너지 출입과 실생활 활용

  • 열에너지 흡수 (주위 온도 낮아짐): 융해, 기화, 승화(고→기)

    • 가열 곡선의 평탄면: 가해준 열에너지가 상태 변화에 사용되므로 온도가 유지됨.

    • 실생활 예: 젖은 빨래/땀이 마르면 시원함(기화), 냉장고 증발기에서 냉매 기화, 드라이아이스 흡열.

  • 열에너지 방출 (주위 온도 높아짐): 응고, 액화, 승화(기→고)

    • 냉각 곡선의 평탄면: 방출하는 열에너지 때문에 온도가 일정하게 유지됨.

    • 실생활 예: 이글루/과수원에 물 뿌리기(물이 얼며 열 방출), 파라핀 치료기 응고열.

  • 컴퓨터 CPU 히트 파이프: 파이프 내부 냉매가 CPU 열을 받아 기화하여 이동한 뒤, 식으면서 액화되는 과정을 끊임없이 반복하여 열을 식힘.
